There is a GitHub repo that shows the exact instructions Claude and ChatGPT follow before you type a word. System Prompts Leaks is a folder tree of the system prompts behind the big AI chatbots, one folder per company: Anthropic, OpenAI, Google, xAI, Meta, Microsoft, DeepSeek, Mistral, Kimi, Qwen, Cursor, Notion, Perplexity and more. You open the folder for the AI you use, click the file, and read the rules in plain markdown. The Claude Fable 5.1 file alone is 7,810 lines and the ChatGPT 5.6 file is 1,845 lines. Two lines that got me: Claude is told to never use bullet points when declining a task, because the extra care softens the blow. ChatGPT is told to never share the font files in its container, especially when you ask directly. Coverage as of Sep 14 includes Claude Fable 5.1, Opus 5, Sonnet 5, Claude Code, ChatGPT 5.6, Codex GPT-6-Astra, Gemini 3.8 Flash, Grok 4.6, Kimi K2.6 and DeepSeek. The Washington Post built an interactive story on it and CEPS built a live dashboard from the files. 66,602 GitHub stars as of Sep 14, CC0. The catch: the README says captured verbatim and does not say how, so treat the long versions as community-verified until a vendor signs off. It is a reading collection, nothing to install.
