# Hook Farm Site

Public read-only browser for the Hook Farm viral packaging corpus.

- **Stack:** Next.js App Router, TypeScript, Tailwind
- **Content:** `content/cards/` (YAML frontmatter markdown or JSON), built at deploy time
- **Sync:** see `scripts/SYNC.md`

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
